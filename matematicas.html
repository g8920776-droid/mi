📊 Recurso 1: Organizador Gráfico - Métodos de Sistemas de Ecuaciones

Esquema sinóptico de clasificación de los métodos algebraicos y gráficos para resolver sistemas de ecuaciones lineales con dos incógnitas.

📈 Método Gráfico

Consiste en representar ambas ecuaciones en un plano cartesiano mediante tabulación ((x, y)).

Solución: El punto de intersección ((x, y)) donde se cruzan las rectas.

➕ Suma y Resta

Iguala coeficientes con signos opuestos para eliminar una variable al sumar las ecuaciones.

Pasos: Multiplicar, eliminar, despejar y sustituir.

🧮 Regla de Cramer

Emplea determinantes y productos cruzados para hallar rápidamente el valor de cada incógnita.

Fórmula: x = Ax / As ; y = Ay / As
